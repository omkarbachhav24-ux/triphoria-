# TRIPHORIA Visual Language

## Editorial Composition

TRIPHORIA uses editorial layout principles, not SaaS template grids.

**Core principles:**
- Typography is structure, not just content
- Media is the visual anchor, not decoration
- Asymmetry creates energy and hierarchy
- Empty space must be intentional
- Each section should feel like a different scene

## Visual Anchors

Every major section needs a dominant visual element:
- Large video/media frame
- Oversized typography
- Color field
- Editorial grid
- Technical metadata composition

## Density Strategy

Density comes from meaningful content, not from filling space:
- Media (video thumbnails, photography)
- Typography variation (display → body → mono)
- Metadata (project IDs, timestamps, technical specs)
- Color blocks (teal, lime, deep teal fields)
- Layered compositions (text over media, overlapping elements)

## Asymmetry

Avoid symmetrical three-column grids. Use:
- Large left + small right (60/40, 70/30)
- Small left + large right
- Full-width + offset content
- Staggered grid with varying heights
- Horizontal strips with vertical breaks

## Section Rhythm

Alternate section compositions to create visual rhythm:
1. Full-width media
2. Asymmetric text + image grid
3. Large typography over color field
4. Horizontal project strip
5. Editorial list with metadata
6. Full-width color block with centered content
7. Large number + explanation

Never repeat the same composition pattern in adjacent sections.

## Three-Level Depth System

**Level 1 — Environment**: `--background` (#111111), subtle texture, environmental SVG, ambient video
**Level 2 — Surface**: `--surface` (#1A1A1A), functional containers, navigation, media frames
**Level 3 — Interaction**: `--primary` (#00CDB8), buttons, hover, cursor, focus, menus, transitions

## Media Treatment

- Large, dominant media presence
- Authentic aspect ratios (no forced squares)
- Letterboxing and crop marks for cinematic feel
- Timecode metadata overlays
- Editorial framing (not centered thumbnails in cards)

## Color-Block Strategy

Use full-width color fields to create section transitions:
- Deep teal (`--teal-deep`) for emphasis sections
- Ink (`--background-dark`) for cinematic sections
- Primary teal (`--primary-muted`) for highlight areas
- Accent lime for high-energy moments (sparingly)

## Typography-as-Structure

Headlines are compositional elements:
- Short statements with intentional line breaks
- Controlled max-width for reading rhythm
- Weight variation within a single heading
- Monospace metadata as visual texture alongside display type
